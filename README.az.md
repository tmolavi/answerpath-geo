# AnswerPath GEO — Azərbaycan dili

AnswerPath GEO biznes seçməzdən əvvəl istifadəçilərin süni intellektə verə biləcəyi sualları FAQ, məzmun və GEO planlaması üçün kəşf edir.

## Sürətli istifadə

```bash
pip install answerpath-geo
answerpath "e-ticarət üçün SEO məsləhəti"
```

`observed` sizin məlumatınızda həqiqətən görünən sualdır; `generated` araşdırma hipotezidir və real tələb demək deyil.

Alət lokal işləyir; API açarı, LLM, GPU, Hugging Face və hesab girişi tələb etmir. Quraşdırmasız demo üçün [Hugging Face](https://huggingface.co/spaces/taqimolavi/answerpath-geo) səhifəsini açın.
