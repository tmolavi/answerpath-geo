# AnswerPath GEO — راهنمای فارسی

AnswerPath GEO سؤال‌هایی را که ممکن است کاربران پیش از انتخاب یک کسب‌وکار از هوش مصنوعی بپرسند، برای FAQ، محتوا و GEO پیدا می‌کند.

## استفاده‌ی سریع

```bash
pip install answerpath-geo
answerpath "مشاوره سئو برای فروشگاه اینترنتی"
```

خروجی در `answerpath-output/` ساخته می‌شود. `observed` یعنی سؤال در داده‌ی شما دیده شده و `generated` یعنی فرضیه‌ی پژوهشی ابزار؛ دومی تقاضای واقعی نیست.

این ابزار محلی است و به API، LLM، GPU، Hugging Face یا ورود به حساب‌ها نیاز ندارد. برای دمو بدون نصب از [Hugging Face](https://huggingface.co/spaces/taqimolavi/answerpath-geo) استفاده کنید.
