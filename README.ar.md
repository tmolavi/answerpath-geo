# AnswerPath GEO — العربية

يكتشف AnswerPath GEO الأسئلة التي قد يطرحها المستخدمون على الذكاء الاصطناعي قبل اختيار نشاط تجاري، لاستخدامها في الأسئلة الشائعة والمحتوى وGEO.

## استخدام سريع

```bash
pip install answerpath-geo
answerpath "استشارات تحسين محركات البحث للمتاجر الإلكترونية"
```

تعني `observed` أن السؤال ظهر فعلاً في بياناتك، بينما `generated` فرضية بحثية وليست دليلاً على طلب حقيقي.

يعمل البرنامج محلياً ولا يحتاج إلى مفتاح API أو LLM أو GPU أو Hugging Face أو تسجيل دخول. للعرض المباشر دون تثبيت استخدم [Hugging Face](https://huggingface.co/spaces/taqimolavi/answerpath-geo).
