# AnswerPath GEO — Türkçe

AnswerPath GEO, bir işletmeyi seçmeden önce kullanıcıların yapay zekâya sorabileceği soruları FAQ, içerik ve GEO planlaması için keşfeder.

## Hızlı kullanım

```bash
pip install answerpath-geo
answerpath "e-ticaret SEO danışmanlığı"
```

`observed` sizin verinizde gerçekten görülen sorudur; `generated` araştırma hipotezidir ve gerçek talep anlamına gelmez.

Araç yerel çalışır; API anahtarı, LLM, GPU, Hugging Face veya hesap girişi gerekmez. Kurulumsuz demo için [Hugging Face](https://huggingface.co/spaces/taqimolavi/answerpath-geo) sayfasını açın.
