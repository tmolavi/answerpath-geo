# Research Collaboration: Question Discovery & Intent Stratification

AnswerPath GEO welcomes researchers collaborating on:
- Conversational question extraction from raw query logs.
- Semantic clustering and deduplication algorithms.
- Disambiguating observed real user search demand from synthetic prompt hypotheses.

### Ground Rules
All prompt sets generated by AnswerPath GEO must maintain strict provenance metadata (`source_type: "observed" | "generated"`).

Propose new research query corpora in [GitHub Discussions (Research)](https://github.com/tmolavi/answerpath-geo/discussions).
